What is here

The downloadable bundle includes the manifest, source registry, and the current JSON tables. Each source entry names the publisher, publication or version, retrieval date, intended use, and the primary link where available.

This data is not a client plan and does not contain household information. It is shared planning reference data used by both RP editions.

Maintenance

Reference data is reviewed as publishers release new tax, Medicare, Social Security and other authoritative material. A new bundle is tested before it becomes part of an RP release. The app records the data vintage so an advisor can tell which figures were in force when a plan or report was prepared.

For how the data is selected, checked, and carried into the engine, read the methodology and calculation validation report.
